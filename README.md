# Привет, я Элина

Linux-инженер. Занимаюсь администрированием и автоматизацией серверов на
Debian и Ubuntu: настройка, защита, диагностика.

## Стек

- **ОС:** Linux (Debian, Ubuntu), systemd
- **Автоматизация:** Bash, Ansible
- **Безопасность:** SSH hardening, ufw, fail2ban, sysctl, изоляция сервисов в systemd
- **Веб:** nginx
- **CI:** GitHub Actions, ShellCheck, ansible-lint, yamllint

## Проекты

| Проект | О чём |
|---|---|
| [ansible-server-setup](https://github.com/Elylya-hash/ansible-server-setup) | Ansible-плейбук для подготовки сервера: пользователи, фаервол, защита SSH, fail2ban, nginx. CI применяет плейбук и проверяет идемпотентность |
| [linux-admin-scripts](https://github.com/Elylya-hash/linux-admin-scripts) | Bash-скрипты для бэкапов, контроля дисков и сервисов, аудита учётных записей. ShellCheck и тесты в CI |
